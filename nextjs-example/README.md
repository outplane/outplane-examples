# Next.js Random Science Facts

A minimal Next.js 15 app with shadcn/ui that displays random science facts about physics, biology, chemistry, astronomy, geology, and mathematics.

## Features

- 30 curated science facts across 6 categories
- Beautiful dark UI with gradient styling
- Animated transitions between facts
- Category badges with icons
- Fully responsive design

## Run with Docker

```bash
docker build -t nextjs-example . && docker run --rm -p 8080:8080 nextjs-example
```

Then open http://localhost:8080

## Tech Stack

- Next.js 15
- React 19
- Tailwind CSS
- shadcn/ui components
- Lucide React icons
